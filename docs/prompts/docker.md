Проблема: Данное ПО имеет существенное ограничение поставки в другие системы, нужно производить установку в систему CLI cargo install tldr-cli и дальнейшее использование в терминале
Задача: Необходимо реализовать возможность поставки данного ПО как докер образ и использования CLI без установки в целевой проект
Результат: в любом проекте я могу использовать все функции tldr-cli без установки вызывая инструмент 
похожим образом
docker pull ghcr.io/united-software-platform/tldr-code:latest

docker run --rm \
  -u "$(id -u):$(id -g)" \
  -v /путь/к/проекту:/project:ro \
  -v "$PWD/out:/out" \
  ghcr.io/united-software-platform/tldr-code:latest
